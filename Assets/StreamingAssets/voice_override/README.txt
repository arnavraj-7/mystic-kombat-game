Voice overrides (local only)
============================
Drop an .ogg, .wav or .mp3 file here and the game plays it instead of the built-in line.
The file name is the line key. Audio files in this folder are git-ignored, so they never get pushed.

In a built game this folder is:  MysticKombat_Data/StreamingAssets/voice_override/

Fighter lines   <fighter>_<line>     fighters: kazu goro shin zevrin rio kuro sho ren kai hana malgrath
                                     lines:    s1 s2 s3 (specials)  ult  hurt  ko  win
                examples: ren_ult.ogg   kazu_s2.wav   goro_ult.mp3

Announcer       round_1 round_2 round_3 final_round fight ko perfect time_up p1_wins p2_wins draw
                choose_fighter  name_<fighter>

Restart the game after adding files.
